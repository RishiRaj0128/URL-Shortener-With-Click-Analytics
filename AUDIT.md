## Executive Summary

This audit assesses the alignment between what the repository claims in [`README.md`](file:///d:/URL%20Shortener%20with%20Click%20Analytics/README.md), [`backend/SYSTEM_DESIGN.md`](file:///d:/URL%20Shortener%20with%20Click%20Analytics/backend/SYSTEM_DESIGN.md), [`INCIDENTS.md`](file:///d:/URL%20Shortener%20with%20Click%20Analytics/INCIDENTS.md), and resume-facing documentation versus what is genuinely implemented in executable code, tests, and benchmark results.

### Key Findings:
1. **Critical Inconsistency in Short Code Generation**: Documentation claims "6-character, 56.8B codes, collision-free" Base62 encoding. However, the system actually generates 64-bit Snowflake IDs (`SnowflakeIdGenerator`), which encode to **10 to 11 Base62 characters** without truncation. The 6-char / 56.8B claim is mathematically valid only for small sequential database IDs ($62^6 \approx 56.8 \times 10^9$), not for 64-bit Snowflake IDs.
2. **Multi-Instance Concurrency Deficits**: In-memory state storage breaks multi-node correctness. Rate limiting (`RateLimitingService`) uses local `ConcurrentHashMap` (yielding an effective 3x limit across 3 instances). Anomaly detection velocity windows and rolling baselines (`AnomalyDetector`) are stored in JVM heap maps, allowing distributed bot bursts across nodes to bypass detection.
3. **Insecure IP Hashing**: Privacy tracking uses plain, unsalted SHA-256 (`IpHashUtil`). Because IPv4 contains only $2^{32}$ addresses, unsalted hashes are vulnerable to rainbow table precomputation and offline reversal within minutes.
4. **Scope Mismatch in Routing**: `BanditRouter` and `EwmaNodeScorer` are sophisticated in-memory implementations that reference banking/payment gateways (HDFC, ICICI, Axis), but are **never invoked during URL redirection** (`RedirectController`). The cluster relies solely on static Nginx upstream routing.
5. **Observability & Testing Gaps**: Custom Prometheus metrics are not registered via `MeterRegistry`; no Grafana or Prometheus containers exist in `docker-compose.yml`. Integration tests run against in-memory H2 rather than Testcontainers. Single-stage Dockerfile runs as root. No Terraform exists.
